CODE 01
HONOR

榮譽

承認失敗，不找藉口。

倒三角形——穩固根基，直面挑戰。它象徵著我們不屈的意志與穩固的根基。在風暴與挑戰面前，我們如同紮根大地的磐石，將每一次打擊轉化為向下的力量。無論世界如何動盪，我們始終屹立不搖。

CODE 02
COURAGE

勇氣

承擔後果，絕不逃避。

蒙空鯊魚——主動出擊，求勝渴望。這不僅僅是一條鯊魚，它是海洋中的頂級掠食者，是我們靈魂深處對勝利的渴望。在人生的海洋中，我們拒絕做被動的獵物，而是主動出擊的戰士，用行動和實力去爭取屬於自己的榮耀。

CODE 03
FAITH

信念

親手重建，絕不認輸。

海錨——堅定信念，人生航標。在波濤洶湧的人生大海中，海錨是我們最堅實的依靠。無論遭遇多大的風浪，信念如錨，讓我們在失敗後親手重建，絕不認輸，始終鎖定那個「為自己贏一次」的目標。
